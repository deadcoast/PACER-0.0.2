# WELL and THEATRE

PACER should provide the agent with **more usable context**, not repeatedly dump more tokens.

## WELL

The WELL is the durable project knowledge reservoir:

- MIVIM spec;
- source anchors;
- architecture/canon;
- prior decisions;
- approved nodules;
- phase history;
- research references;
- future dependencies.

It is broad and queryable.

## THEATRE

The THEATRE is the current actionable slice:

- global objective;
- current phase objective;
- current/nearby paces;
- relevant source anchors;
- inherited decisions/latches;
- known dependencies that the current work can affect;
- phase exit condition;
- next known phase.

Theatre compilation prevents both extremes:

1. **amnesia** — working on one pace with no global plan;
2. **token flooding** — rereading the entire project before every small change.

The included `pacer theatre` command demonstrates this behavior.
