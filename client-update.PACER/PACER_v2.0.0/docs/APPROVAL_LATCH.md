# Approval / Skip Latching

PACER approvals are state, not conversation etiquette.

```text
+approved NDL-003
->:absorb::nodule NDL-003 into=overlord
```

Once an approval or explicit skip has been recorded, downstream paces inherit it automatically.

A new session, a different sub-agent, a new phase, or a validation step does not erase it.

Reopen only on material subject change. When reopened, state **what changed** rather than asking the original question again from zero.
